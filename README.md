# Inkbow: The Last Guardian

A watercolor archer defense game for phone and PC. One HTML file, no build step, no assets.

## Play

Open `index.html`, or visit the Vercel deployment.

## Controls

| Action | Touch | PC |
| --- | --- | --- |
| Aim and shoot | Drag, pull back, release | Click and drag, release |
| Shield (tap late to deflect) | Shield button | Space or right-click |
| Spirit arrows (Ember, Storm, Gale) | Buttons, bottom left | 1 / 2 / 3 |
| Starfall | Star button | E |
| Pause | Pause button | Esc |

## Features

- Five realms, each ending in a boss, plus Endless mode
- Enemy archers with eight arrow types, walkers, riders
- In-run perks, permanent skill tree, bow that evolves with lifetime kills
- All art painted in code on canvas; all sound synthesized with Web Audio
